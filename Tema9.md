```python
class Icecream:
    def __init__(self, ingredient=None):
        if isinstance(ingredient, str):
            self.ingredient = ingredient
        else:
            self.ingredient = None
            
    def composition(self):
        if self.ingredient:
            print(f"Мороженое с {self.ingredient}")
        else:
            print('Обычное мороженое')

icecream = Icecream()
icecream.composition()
icecream = Icecream('шоколадом')
icecream.composition()
icecream = Icecream(5)
icecream.composition()

Давайте вместе с вами реализуем программу с полиморфизмом, которая будет описывать всю суть первого предложения задачи. Для этого мы можем выбрать два языка, например, русский и английский и написать для них отдельные классы, в которых будет в виде атрибута слово, которым здороваются на этих языках. А также напишем функцию, которая будет выводить информацию о том, как на этих языках здороваются. Заметьте, что для решения поставленной задачи мы использовали декоратор @staticmethod, поскольку нам не нужны обязательные параметры-ссылки вроде self.


```python
class Russian:

    @staticmethod
    def greeting():
        print("Привет")

class English:
    @staticmethod
    def greeting():
        print("Hello")

def greet(language):
    language.greeting()

ivan = Russian()
greet(ivan)
John = English()
greet(John)
   
```

2. Статические методы: Оба метода greeting() объявлены с декоратором @staticmethod (не требуют доступа к экземпляру класса (self)).

3. Функция greet(): Принимает любой объект, у которого есть метод greeting(). Вызывает этот метод независимо от конкретного класса объекта.

## Общие выводы по теме
В Python класс - это шаблон или формальное определение, которое определяет состояние и поведение объектов определенного типа. Классы являются основным строительным блоком объектно-ориентированного программирования в Python. Они позволяют создавать объекты, которые являются экземплярами класса, и определять, как эти объекты будут работать и взаимодействовать. Методы - это функции, определенные внутри класса, которые выполняют операции с объектами класса или его атрибутами. Методы могут иметь доступ к атрибутам класса и объектам через параметр self. Они могут быть объявлены внутри класса и могут быть вызваны на объектах класса. Экземпляры классов являются конкретными объектами, созданными на основе определения класса. Каждый экземпляр представляет отдельный и независимый объект, имеющий свои собственные свойства и методы. Динамическое изменение экземпляров классов позволяет добавлять, изменять или удалять атрибуты и методы на существующих экземплярах классов. Это означает, что вы можете динамически изменять свойства и поведение объектов во время выполнения программы. Статические и классовые методы предоставляют специальные типы методов, которые могут быть определены внутри класса и вызываться без необходимости создавать экземпляр класса. Эти методы предоставляют функциональность, связанную с классом, а не с конкретными экземплярами. Инкапсуляция - это механизм, который позволяет скрывать внутренние детали реализации класса и предоставлять только необходимый интерфейс для взаимодействия с объектами. Она позволяет обеспечить безопасность данных и контроль доступа к атрибутам и методам класса. Ассоциация описывает отношение между двумя классами, где один класс использует функциональность или имеет зависимость от другого класса. Ассоциация позволяет взаимодействовать между объектами разных классов и создавать более сложные структуры программы.
Полиморфизм позволяет объектам одного типа иметь различное поведение в зависимости от контекста. Он позволяет использовать одно и то же имя метода или оператора для объектов разных классов, что облегчает разработку гибких и расширяемых программ.
