## Лабораторная работа №2
### ⦁	Класс итератор с гибкой настройкой и удобными применением.


```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self

    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__ == '__main__':
    counter = CountDown(5)
    for i in counter:
        print(i)   
```

1.__iter__ возвращает сам объект, делая его итератором

2.__next__ определяет логику получения следующего значения

3.StopIteration исключение сигнализирует о завершении итерации

4.Начальное значение start + 1 позволяет включить 0 в отсчет

## Лабораторная работа №5
### ⦁ Такой же счетчик, как и в первом задании, только это генератор и использует yield.


```python
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)   
```
### Результат.
![Меню](https://github.com/Freeman-glitch/software-engineering/blob/tem_11.md/pic/Lab5.png)

## Выводы

В данном коде идет работа с генератором:

1.Состояние сохраняется между вызовами next()

2.Локальные переменные (включая параметры) сохраняют свои значения

3.Выполнение приостанавливается на yield и возобновляется при следующем вызове

## Самостоятельная работа №1
### ⦁	Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.


```python
def fib(n):
    a, b = 1, 1
    count = 0

    while count < n:
        yield a
        a, b = b, a + b
        count += 1

n = 200
fibonacci_200 = None
for i, num in enumerate(fib(n), 1):
    if i == n:
        fibonacci_200 = num
        break

print(f"200-е число Фибоначчи: {fibonacci_200}")  
```

![Меню](https://github.com/Freeman-glitch/software-engineering/blob/tem_11.md/pic/Solo1.png)

## Выводы

В данном коде идет работа с итератором:

1.Генератор fib(n):Начинает с a, b = 1, 1. В цикле while count < n генерирует n чисел yield, a возвращает текущее число Фибоначчи a, b = b, a + b, обновляет значения для следующей итерации.

2.Основная логика: for i, num in enumerate(fib(n), 1) перебирает числа с индексацией с 1, когда i == n, сохраняет 200-е число в fibonacci_200, прерывает цикл с помощью break
  
## Самостоятельная работа №2
### ⦁	К коду предыдущей задачи добавьте запоминание каждого числа Фибоначчи в файл “fib.txt”, при этом каждое число должно находиться на отдельной строчке. Результатом выполнения задачи будет листинг кода и скриншот получившегося файла.


```python
def fib(n):
    a, b = 1, 1
    count = 0

    while count < n:
        yield a
        a, b = b, a + b
        count += 1

n = 200
fibonacci_200 = None

with open("fib.txt", "w", encoding="utf-8") as file:
    for i, num in enumerate(fib(n), 1):
        file.write(f"{num}\n")

        if i == n:
            fibonacci_200 = num
            break

print(f"200-е число Фибоначчи: {fibonacci_200}")
print("Все числа Фибоначчи записаны в файл 'fib.txt'")   
```

## Общие выводы по теме
Итераторы (iterators) - это объекты в Python, которые позволяют последовательно обходить элементы в какой-либо структуре данных, например, в списке, кортеже, множестве или строке. Они предоставляют удобный интерфейс для доступа к элементам коллекции без необходимости знать детали ее внутренней реализации. Генераторы в Python - это специальный тип функций или выражений, которые позволяют создавать итераторы более эффективным способом. Генераторы позволяют генерировать значения последовательно по одному элементу за раз без необходимости хранения всей последовательности в памяти.
